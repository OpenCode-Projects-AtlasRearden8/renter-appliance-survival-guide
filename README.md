# The Renter Appliance Survival Guide

A friendly, plain-English manual for the five appliances everyone lives with — **dishwasher, washer, dryer, refrigerator, and HVAC basics** — written for people with zero hardware-store background. Explains AI-era home repair the way a friend would: step by step, never condescending.

## What's inside

- **docs/** — the manual itself, in Markdown, one file per topic:
  - Appliance chapters (dishwasher, washer, dryer, fridge, HVAC): *what error codes honestly mean*, filters/coils/gaskets worth cleaning monthly, when to call a pro, and reset basics.
  - `replace-vs-keep.md` — the energy-hog math in plain dollars (replace the old fridge; keep the dishwasher).
  - `reset-basics.md` — power cycles, control locks, firmware wisdom.
  - Take-along sheets: **error-code log sheet**, **call-a-pro checklist**, and a **glossary**.
- **build.py** — one dependency-light build script that turns `docs/` into a static HTML site in `site/` (built locally, no network needed).
- **tests/** — a `unittest` suite covering link rewriting, page templating, and the full build.

Complements the *home-repair-with-ai-guide* and *home-maintenance-mcp-server* projects in the Asdale Dynamics learning library.

## Quick start

Requirements: Python 3.10+ and the `markdown` package (`pip install markdown`).

```bash
# Run the tests
python3 -m unittest discover -s tests -v

# Build the static site
python3 build.py

# Build and print the location of the built index.html
python3 build.py --open
```

Then open `site/index.html` in any browser — it is a fully local, offline copy of the whole guide.

To reorganize or add chapters: add a Markdown file to `docs/`, then list it in `NAV_PAGES` in `build.py`. The build will deliberately fail with a clear message if a nav entry is missing a doc (or a doc is missing from the nav), which keeps the site honest.

## Who it's for

Renters and first-time homeowners who want fewer surprise appliance bills: what a blinking `E24` actually means, the 3-minute monthly habits that prevent most service calls, the line between "I can clean that" and "call a licensed tech," and how to survive a technician visit with documents and dignity (see the call-a-pro checklist).

**This guide is education, not a repair manual or professional advice.** Always follow your appliance's own manual; treat gas, refrigerant, roof work, water-near-power, and repeated breaker trips as pro territory. Emergency numbers are in the call-a-pro checklist — add your local ones.
