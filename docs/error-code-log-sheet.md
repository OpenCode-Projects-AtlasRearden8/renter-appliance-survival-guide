# Error-Code Log Sheet

**Print this page, or copy the table into your notes/sheet app of choice.** The rule that makes the sheet work: write the code down **before** you search the web or call anyone. One appliance, one page (start a fresh page per appliance — patterns per machine are what techs want to see).

## How to fill it in

- **Appliance/Model:** check the sticker — inside the door frame, on the back, or behind the toe-kick. The *model number* (not serial) is the useful one.
- **What happened first:** what you were doing when the code appeared. Techs and support lines ask this within 10 seconds.
- **What fixed it (if anything):** cleans, resets, parts. This column is where the magic lives — it's the pattern per appliance, and if you rent, it's your paper trail.

## Reminder card (cut out or bookmark)

1. **Code appears** → write it down *exactly* (letters, dashes, blinking counts).
2. **One full reset** (60 seconds, no power). Still wrong? Log round two.
3. **Chapter cleaning checklist** for that appliance → re-test on a light load/cycle.
4. **Twice or more = stop fiddling** → [call-a-pro checklist](call-a-pro-checklist.html), sheet in hand.
5. Under warranty/service plan? **Log dates before you call** — the sheet is your evidence.

*Tip: photograph the log sheet page when it's full — printed sheets drink coffee.*
